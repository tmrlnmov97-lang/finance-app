# Финансы

Личное приложение учёта денег. Статическая страница на GitHub Pages,
данные — в Supabase (таблица `finance_state`, одна строка на пользователя,
доступ ограничен политиками RLS).

- `index.html` — приложение целиком, включая экран входа.
- `config.js` — адрес проекта Supabase и публичный anon-ключ.
- `schema.sql` — таблица и политики доступа, выполнить один раз.

Личных цифр в репозитории нет: приложение стартует пустым и подтягивает
данные из Supabase после входа.
